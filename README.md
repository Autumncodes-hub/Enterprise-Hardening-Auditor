# Enterprise Hardening Auditor (EHA)

An automated Infrastructure VAPT (Vulnerability Assessment and Penetration Testing) auditing tool written in Python. It evaluates target servers and network endpoints for critical configuration weaknesses and compliance gaps based on **CIS Benchmarks**.

Designed specifically for Infrastructure Security Analysts auditing corporate and banking (BFSI) environments where safe, non-disruptive banner-grabbing and protocol negotiation are required.

## ⚡ Key Features
* **Cryptographic Strength Auditor (Port 443):** Probes supported SSL/TLS configurations, flagging deprecated protocols (SSLv2, SSLv3, TLS 1.0, TLS 1.1) vulnerable to MITM attacks.
* **SSH Configuration Auditor (Port 22):** Performs banner-grabbing to identify outdated OpenSSH distributions or legacy SSHv1 deployment ranges.
* **SMB Signing Verification (Port 445):** Audits SMB security parameters to flag disabled or optional message signing states susceptible to NTLM Relay attacks.
* **Robust Exception Handling:** Features graceful fallbacks and port filtering logic to ensure network execution never halts mid-scan.
* **Enterprise Reporting Engine:** Compiles JSON findings into a production-ready, beautifully structured standalone HTML report complete with CVSS-aligned severity indicators.

## 🚀 Installation & Requirements
The script uses lightweight native Python libraries. Advanced SMB configuration checks automatically scale if `nmap` is present in the local path environment.

```bash
# Clone the repository
git clone https://github.com
cd Enterprise-Hardening-Auditor

# Verify Python version (Python 3.8+ recommended)
python3 --version
```

## ⚙️ Usage
To execute a non-intrusive configuration security baseline assessment against a network asset, run:

```bash
python3 eha.py <target_ip_or_domain> --output report.html --json results.json
```

### Argument Flags
* `<target>`: Specify target host IP address or domain string.
* `--timeout`: Custom socket connectivity timeout threshold in seconds (Default: 5s).
* `--output`: Custom output path string for the compiled HTML executive report.

## 🔒 Disclaimer
This tool is built strictly for authorized security baseline audits, system hardening reviews, and defensive blue-team network hygiene checks. Ensure explicit authorization (Letter of Attestation/Scope Document) is acquired prior to infrastructure testing.
